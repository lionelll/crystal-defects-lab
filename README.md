# 晶体缺陷可视化实验室

独立的本地前端应用。首次 GitHub 代码基线按用户当次要求保存在 `main`；这不表示科学验收、正式发布或服务器部署。正式版本号、测试及正式服务器路径仍待确认。

共用界面参数与本地验收流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev -- --port 4173
```

打开 `http://127.0.0.1:4173/defects/`。`/defects/` 是供入口页联调的本地静态资源基路径，尚非已登记的服务器路由。

```bash
npm test
npm run build
npm run preview -- --port 4174
```

`preview` 对应 `http://127.0.0.1:4174/defects/`。生产静态文件生成在本仓库 `dist/`，本项目尚未部署。

## 页面范围

五个模块、十五个子场景；Three.js 支持旋转、缩放、平移与视角重置。动画可播放、暂停、重置、单步与拖动进度。科学依据和仍需学科审定的构型记录在工作区 `文档/02-设计与验收/`。所有画面均为有限原子区域的教学几何示意，不是位错芯的原子级仿真。

页面外壳使用与晶体结构、三元相图、二元相图一致的深色品牌视觉；`src/shared-lab-theme.css` 保存本项目独立的主题实现。PRD 的“明亮”表述与用户最新要求的差异已记录于工作区 `文档/02-设计与验收/晶体缺陷视觉规范差异记录.md`。

本项目独立保存 Logo、源码与依赖；不会在运行时引用父目录或其他项目仓库。正式部署由 `10-部署发布` 在路径和当次操作获准后执行。
