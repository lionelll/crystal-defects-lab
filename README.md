# 晶体缺陷可视化实验室

独立的前端应用。首次 GitHub 代码基线按用户当次要求保存在 `main`；这不表示科学验收、正式发布或服务器部署。测试目标已登记，正式版本号及正式服务器路径仍待确认。

共用界面参数与本地验收流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

本项目后续在 `dev` 开发，`release` 用于获准发布，`main` 在发布验收后同步 `release`；分支职责与授权边界以本项目 `AGENTS.md`、`DEVELOPMENT.md` 及用户最新当次指令为准。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev -- --port 4173
```

打开 `http://127.0.0.1:4173/defects/`。`/defects/` 同时是本地静态资源基路径和已登记测试目标的路径；本地可运行不表示测试服务器已经上线。

```bash
npm test
npm run build
npm run preview -- --port 4174
```

`preview` 对应 `http://127.0.0.1:4174/defects/`。生产静态文件生成在本仓库 `dist/`。已登记测试地址为 `http://123.57.11.145:8080/defects/`，唯一测试部署根为 `/var/www/defects-dev`；尚未确认测试页上线。

本项目已准备与其他实验室同类的 `dev` 测试自动部署工作流，说明见 [DEVELOPMENT.md](DEVELOPMENT.md)。在用户或云平台管理员完成 `/defects/` 公共映射、目录权限、可信主机身份和本项目独立受限部署凭据前，仓库变量 `DEFECTS_TEST_READY` 保持未启用；工作流存在不表示测试站已部署。

## 页面范围

五个模块、十五个子场景；Three.js 支持旋转、缩放、平移与视角重置。动画可播放、暂停、重置、单步与拖动进度。科学依据和仍需学科审定的构型记录在工作区 `文档/02-设计与验收/`。所有画面均为有限原子区域的教学几何示意，不是位错芯的原子级仿真。

页面外壳使用与晶体结构、三元相图、二元相图一致的深色品牌视觉；`src/shared-lab-theme.css` 保存本项目独立的主题实现。PRD 的“明亮”表述与用户最新要求的差异已记录于工作区 `文档/02-设计与验收/晶体缺陷视觉规范差异记录.md`。

本项目独立保存 Logo、源码与依赖；不会在运行时引用父目录或其他项目仓库。测试公共映射、目录权限及本项目受限可信登录由用户或云平台管理员预置；条件就绪并获当次授权后，本项目负责人自行部署、验证及回滚本项目测试版本。正式部署和正式回滚仍由 `10-部署发布` 执行；现不得因已有测试包就尝试服务器连接。
