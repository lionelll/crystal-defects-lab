# 晶体缺陷可视化实验室

独立的前端应用。测试页已在 `/defects/` 上线；这不表示科学验收或正式发布。正式版本号及正式服务器路径仍待确认。

共用界面参数与本地验收流程见 [DEVELOPMENT.md](DEVELOPMENT.md)。

本项目首次正式发布并打 Tag 前在 `dev` 开发；之后新版本在用户确认的唯一 `feature/vMAJOR.MINOR.PATCH` 开发，再经批准进入 `dev`。`release` 用于获准正式发布，`main` 在发布验收后同步 `release`；具体授权见本项目 `AGENTS.md`、`DEVELOPMENT.md` 及公共《实验项目统一开发与测试发布规范》。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev -- --port 4173
```

打开 `http://127.0.0.1:4173/defects/`。`/defects/` 同时是本地静态资源基路径和已上线测试页的路径。

```bash
npm test
npm run build
npm run preview -- --port 4174
```

`preview` 对应 `http://127.0.0.1:4174/defects/`。生产静态文件生成在本仓库 `dist/`。测试地址为 `http://123.57.11.145:8080/defects/`，唯一测试部署根为 `/var/www/defects-dev`；当前公网版本可通过 `/defects/release.json` 查询。

本项目已有 `dev` 测试自动部署工作流，说明见 [DEVELOPMENT.md](DEVELOPMENT.md)。按公共新规范的工作流调整目前**仅在本地**，尚未提交、推送或部署；现有测试站仍运行 `7d75ce6b01f2b15334e93442da9ce11d63617aa4`。下次推送前须按文档迁移本仓库独立的 Actions Secrets，并取得该次推送和测试部署授权。

## 页面范围

五个模块、十五个子场景；Three.js 支持旋转、缩放、平移与视角重置。动画可播放、暂停、重置、单步与拖动进度。科学依据和仍需学科审定的构型记录在工作区 `文档/02-设计与验收/`。所有画面均为有限原子区域的教学几何示意，不是位错芯的原子级仿真。

页面外壳使用与晶体结构、三元相图、二元相图一致的深色品牌视觉；`src/shared-lab-theme.css` 保存本项目独立的主题实现。PRD 的“明亮”表述与用户最新要求的差异已记录于工作区 `文档/02-设计与验收/晶体缺陷视觉规范差异记录.md`。

本项目独立保存 Logo、源码与依赖；不会在运行时引用父目录或其他项目仓库。测试公共映射、目录权限及本项目受限可信登录已经核验；后续公共设施变更仍由用户或云平台管理员按当次授权处理。本项目负责人按授权部署并验证测试版本；测试失败不自动回滚，需要恢复时另获当次手动回滚授权。正式部署和正式回滚仍由 `10-部署发布` 执行。
